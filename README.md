## Installation & Deployment

### Local Testing:
```bash
# Simply open index.html in a web browser
open index.html

# Or use a local server
python -m http.server 8000
# Visit http://localhost:8000
```

### Deployment:
1. Upload all 4 files to your web server
2. Ensure robots.txt is in the root directory
3. Update domain names in robots.txt and sitemap.xml if needed
4. Test on different devices and browsers
5. Submit sitemap to Google Search Console

## Customization Guide

### To Update Colors:
Edit the CSS variables in `<style>` section:
```css
:root {
    --primary-gold: #d4af37;      /* Main accent color */
    --dark-luxury: #1a1a1a;        /* Dark background */
    --light-cream: #f5f1e8;        /* Light background */
    --deep-navy: #1c3144;          /* Navy background */
    --accent-silver: #e8e8e8;      /* Silver accents */
}
```

### To Update Content:
1. Modify text within `<p>` tags
2. Update image URLs in `<img src="">` 
3. Change headings in `<h1>`, `<h2>`, `<h3>` tags
4. Keep "chauffeur service Dubai" anchor only in second paragraph

### To Update Links:
- Instagram link must remain in the second paragraph only
- Currently linked to: https://www.instagram.com/pilotandcar/
- Do not add phone numbers or call buttons
